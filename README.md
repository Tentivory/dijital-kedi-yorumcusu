# 🐱 Dijital Kedi Yorumcusu

**Dünyanın (ve belki de evrenin) en ciddi, en bilimsel ve en anlamsız kedi tercümanı.**

Bu proje, kedilerin miyavlarını derin felsefi sözlere çevirmek için geliştirilmiştir. Bilim camiası henüz farkında değil ama biz çoktan Nobel'e adayız. Kediler onay vermedi, vermeyecek de. Ama kod çalışıyor.

## Özellikler

- **Gerçekten çalışır**: Python 3 ile yazıldı, hiçbir kedi zarar görmedi.
- **Felsefi derinlik**: Her miyav, varoluşsal bir krizi temsil eder.
- **Rastgelelik**: Çünkü kediler de rastgeledir.
- **Gecikme**: Çünkü gerçek hayatta da her şey yavaş olur.
- **Anlamsızlık garantisi**: %100.

## Nasıl Kullanılır?

```bash
python3 kedi_yorumcu.py
```

Kaç miyav yorumlanacağını söyle, o kadar derin söz çıksın. Kediler anlamaz, sen de anlamazsın. Mükemmel.
